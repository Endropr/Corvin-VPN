Инструкция по установке и настройке Corvin VPN

🔑 Вам на почту придёт два ключа:

  • Первый ключ — для компьютера (Windows, macOS, Linux)
  • Второй ключ — для мобильных устройств (обход белых списков)

Оба ключа работают в любом современном VPN-приложении: Happ, V2RayTun, Nekoray и других.

Для компьютера (ПК)

  1. Скачайте любое VPN-приложение:
    • Happ VPN
    • V2RayTun
    • Nekoray

    Для Windows скачивайте файлы с расширением .exe, для macOS — .dmg, для Linux — .AppImage.

  2. Запустите приложение. Если потребуются права администратора — предоставьте их (этим приложениям можно доверять).
  3. Добавьте первый ключ (из письма, для ПК). Обычно в приложении есть кнопка «+», «Добавить», «Import» или «Вставить из буфера».
  4. Проверьте соединение. Нажмите «Test», «Ping» или «SpeedTest» рядом с добавленным ключом.
  5. Нажмите «Подключить» — и наслаждайтесь свободным интернетом!

Для мобильных устройств

  1. Скачайте любое VPN-приложение из официального магазина:
    • V2RayTun (Google Play)
    • V2RayTun (App Store)
    • Happ VPN, Nekoray (Android) — доступны на официальных сайтах

    Для iOS также подходят: Happ, Foxo, Streisand. Установите любое приложение, поддерживающее VLESS/Trojan протоколы.

  2. Скопируйте второй ключ (из письма, для мобильных устройств). Это специальный ключ для обхода белых списков.
  3. Добавьте ключ в приложение: нажмите «+», «Добавить подключение» или «Import», затем выберите «Вставить из буфера» или «Paste from clipboard».
  4. Проверьте соединение кнопкой «Ping» или «Test».
  5. Нажмите «Подключить» — готово! Вы в свободном интернете.

💡 Совет: Если один ключ перестал работать — попробуйте второй. Оба ключа взаимозаменяемы и работают на любых устройствах. Для наилучшей производительности на мобильном интернете используйте второй ключ.
